Обнови страницу Confluence содержимым из локального Markdown-файла.

Используй MCP tool:
- server_name: `confluence-mcp`
- tool_name: `update_page_from_markdown_file`

Важно: эта команда изменяет данные в Confluence. Перед вызовом tool явно предупреди пользователя и попроси подтверждение.

Если пользователь не указал обязательные параметры, сначала попроси их:
- `page_id`
- `file_path`

Поддерживаемые аргументы:
- `page_id` (обязательный)
- `file_path` (обязательный)
- `title`
- `enabled_extensions`

Передавай только те аргументы, которые указаны пользователем или имеют очевидное безопасное значение по умолчанию.

После выполнения кратко покажи результат, важные предупреждения и ошибки.
