Проверь авторизацию и покажи текущего пользователя Confluence.

Используй MCP tool:
- server_name: `confluence-mcp`
- tool_name: `get_current_user`

Если пользователь дал дополнительные параметры, используй их. Если нет, вызывай tool без аргументов.

После выполнения кратко покажи результат, важные предупреждения и ошибки.
