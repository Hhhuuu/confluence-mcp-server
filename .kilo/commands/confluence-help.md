Покажи пользователю список доступных Confluence slash-команд и кратко объясни, для чего каждая нужна.

Команды:
- `/confluence-show-runtime-config` — Показать активный конфиг Confluence MCP.
- `/confluence-plan-pages` — Построить план создания страниц Confluence.
- `/confluence-create-pages` — Создать страницы Confluence по путям.
- `/confluence-current-user` — Проверить пользователя Confluence.
- `/confluence-get-space` — Получить информацию о пространстве Confluence.
- `/confluence-find-page` — Найти страницу Confluence по заголовку.
- `/confluence-get-page` — Получить страницу Confluence по ID.
- `/confluence-move-page` — Переместить страницу Confluence.
- `/confluence-list-markdown-extensions` — Показать Markdown-расширения Confluence bridge.
- `/confluence-export-page-markdown` — Экспортировать страницу Confluence в Markdown.
- `/confluence-export-page-markdown-file` — Экспортировать страницу Confluence в Markdown-файл.
- `/confluence-export-page-tree-markdown-files` — Экспортировать дерево страниц Confluence в Markdown-файлы.
- `/confluence-preview-markdown-storage` — Преобразовать Markdown в Confluence storage без публикации.
- `/confluence-preview-markdown-file-storage` — Преобразовать Markdown-файл в Confluence storage без публикации.
- `/confluence-create-page-markdown` — Создать страницу Confluence из Markdown.
- `/confluence-create-page-markdown-file` — Создать страницу Confluence из Markdown-файла.
- `/confluence-update-page-markdown` — Обновить страницу Confluence из Markdown.
- `/confluence-update-page-markdown-file` — Обновить страницу Confluence из Markdown-файла.
- `/confluence-proofread-page` — Проверить орфографию и пунктуацию страницы Confluence.
- `/confluence-add-proofread-comments` — Добавить inline comments по ошибкам LanguageTool.
